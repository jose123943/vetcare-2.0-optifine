# Evidencias y archivos generados

Aquí se guardan JSON de resultados, salidas de las pruebas, capturas y PDF sintéticos. Cada informe corresponde a su ejecución; las cifras históricas no describen necesariamente la base actual.

Los scripts escriben sus resultados en esta carpeta. El paquete completo incluye las evidencias existentes. `VetCare-web.zip` conserva este documento y el código de pruebas, pero omite capturas y resultados históricos para reducir el tamaño. Ejecutar las pruebas vuelve a generar sus informes.

Los respaldos SQL con filas reales, credenciales, cookies de navegador y fotos privadas permanecen fuera del repositorio y de ambos paquetes.
